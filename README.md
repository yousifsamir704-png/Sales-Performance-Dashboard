# Sales-Performance-Dashboard
## Overview
Interactive Excel dashboard designed to analyze sales performance and monitor key business KPIs.
## Tools Used
- Microsoft Excel
- Power Query
- PivotTables
- Pivot Charts
- Slicers
## Dashboard Features
- Sales Analysis
- Profit Analysis
- Profit Margin Tracking
- Orders Monitoring
- Delivery Performance Analysis
- Customer Segment Analysis
## Key Insights
- Identified top-performing products and categories.
- Evaluated sales trends and profitability.
- Analyzed return rates and delivery KPIs.
- Supported data-driven business decisions.
